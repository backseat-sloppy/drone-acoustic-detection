## AI Disclosure

Generative AI models, including Claude and Copilot, have been used extensively in the development of this project and the accompanying machine learning models. Specifically, GenAI has been used as a tool during the following tasks:

* Gathering research topics.
* Coding scripts.
* Automating/performing setup for training of machine learning models.
* Documenting machine learning model iterations.
* Setting up testing environments.
* Creating documentation pages.
* Other ad-hoc tasks during the project.


Conversely, GenAI has not been used for the following:

* In-depth research and idea generation.
* Unsupervised decision making in development.
* Writing the paper.
