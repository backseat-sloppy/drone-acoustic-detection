# Evaluation

How the detectors are tested, and what the results mean.

Every model in this project is judged on its **confidence**: a number between
0 and 1 for every short window of audio. A good detector gives high confidence
when a drone is present and low confidence when it is not, also in a loud war
soundscape and with other sounds that can be mistaken for a drone.
